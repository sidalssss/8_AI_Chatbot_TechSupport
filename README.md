# AI Chatbot for Technical Support

Bu proje, NLP (Doğal Dil İşleme) teknikleri kullanarak teknik sorulara otomatik ve doğru yanıtlar veren bir akıllı asistan sistemidir.

## Özellikler
- **Niyet Analizi:** Kullanıcının yazdığı mesajlardaki anahtar kelimeleri tespit ederek doğru yanıt kategorisine yönlendirir.
- **Otomatik Yanıt:** Teknik sorunlar için önceden tanımlanmış çözüm önerileri sunar.
- **Öğrenilebilir Yapı:** Daha sonra Transformers veya RNN modelleri ile genişletilebilir modüler mimari.

## Teknolojiler
- Python
- NLP (NLTK/Simple Logic)
- Modüler Algoritma Tasarımı

## Çalıştırma
```bash
python chatbot.py
```
